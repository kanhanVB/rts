# 动作图提示词（垫全家福）

用法：每次**附上全家福图**，复制下面一段发给生图 AI，一段出一张，按标题的文件名保存，打包发我。

- 画风跑偏或长出五官：补一句 `no eyes, no mouth, keep the same flat style as the reference`
- 画出了一整排：补一句 `only one character`
- 站姿图不用出，已从全家福切好
