帝国时代式的直接操控（框选 / 右键），加一层 SuperWEIRD 式的供应链味：**资源不会凭空入账，必须由工人物理扛回基地；出兵要消耗材料组合**。

- 引擎：Godot 4.7.2（`E:\Godot\Godot_v4.7.2-stable_win64.exe`）
- 美术：**王国保卫战风格 2D 手绘贴图**（`art/` 下 58 张：单位姿势、建筑、矿/树、装饰、特效、UI），`-- --noart` 启动可切回程序化画法
- UI：帝国时代式布局（顶栏资源/人口，底栏 命令卡 | 选中信息 | 小地图），皮肤是木板金边面板、羊皮纸提示、红绸波次横幅、金圈头像（九宫格贴图），细线血条；字体参照王国保卫战：起源 中文版用的苹方类黑体——思源黑体 Bold（UI）/ Medium（说明文字），OFL，见 `fonts/OFL.txt`；改文案后跑 `tools/subset_fonts.py` 重新裁字
- 状态：**自动化测试 115 项全过**（采集入库、手动交货、加工链、战斗、建造、胜负判定、行为回归、生产队列、帝国式选择/热键、建筑占格、随机图连通性）
- 方向：**RTS + 基建**为主，塔防（Goo 刷波）保留，作为外部压力


### 生产队列（帝国式）

- 每座基地/兵营最多排 5 个，**排队时就扣钱**，读条完在门口出人（农民 6 秒，兵 8 秒）
- 底栏中间显示队列，排头带进度条和剩余秒数；**点图标取消，全额退钱**
- 人口满了排头读完会等空位；多选同种建筑时自动排进队最短的那座

### 交货策略：为什么默认送仓库

加工厂**不会自动抢货**。默认所有原料原样入库，理由很直接：全自动加工会把木材全烧成木板，
而造农民要 30 木——原料一空就再也补不出人手了。

所以加工是**玩家点名**：选中农民右键熔炉/木工台，这批人才改送加工线（帝国式，全右键完成，没有额外按钮）。
产出口径 1:1（10 矿 → 10 铁锭），送错也不亏——熔炉只吃矿石，木材进去照样按原料入库。
想改回存原料，右键基地或仓库就行。

## 地图

- 默认**随机地图** 3200×2048（约 2.5×2.8 屏），**主城在正中间**，两个巢穴在地图两侧边缘，各有一条土路通向主城
- 主城旁边（开局第一屏里）有一片主林 + 几棵散树，再往外撒十来片林子；主城跟前两片矿，远处 5 片分矿
- 树林是一棵棵能砍的树（每棵 100 木，挡路，砍光变空地）；地图边缘一圈是砍不动的密林；矿堆也挡路，采空变空地
- 生成时保证主城到两个巢穴、到每堆矿都走得通
- 固定种子：命令行末尾加 `-- --seed=N`；老的 1280×720 经典固定图：`-- --classic`（自动化测试用这张）
- 建筑占格：盖好的房子/工地会挡路，A\* 绕着走，不会再直线穿墙顶死

## 玩法循环

1. 开局 3 个工人自动上岗（2 采矿 1 伐木）；之后新造的农民也会自动去干活人少的那种资源
2. 攒资源 → 造仓库（就近收货）/ 熔炉、木工台（把原料变成铁锭、木板）→ 造兵营 → 出兵
3. 60 秒后 Goo 开始刷波（45 秒一波，每波 2 → 19 只，血量每波 +6%），**沿着地图上的土路**朝基地推进
4. **赢**：拆掉所有巢穴，或清完第 10 波；**输**：基地被拆

Goo 的脾气：沿土路行军，路边 150px 内的建筑/工地会被拐过去啃；贴脸（70px 内）才咬单位，被打了必还手；走到路尽头就砸基地。
所以**房子盖在离路远的地方更安全，工人是软肋**——路边矿区的农民会被啃，兵力要守在路上护着物流。
城堡自带箭塔（射程 170，8 伤害 / 1.2 秒），能帮你顶住开局零星几只，挡不住大波。
树林、矿堆旁边不能盖房，右键点进林子会自动落到林子边上。

## 性能

跑基准（120 单位挤在一起混战，直接计时单位逻辑）：

```
Godot --headless --path rts-demo -s bench.gd
```

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 单位逻辑 / 帧（123 单位） | ~17.5 ms（已超 60 帧预算） | ~2.8 ms |
| A\* 寻路 / 次（绕墙长路径） | ~14 ms | ~1.5 ms |

做法：寻路换成原生 `AStarGrid2D`；组成员每帧只取一次（`Unit._group()`）；
分离力用空间哈希只看周围 3×3 桶；Goo / 士兵索敌节流 + 目标粘性；Goo 追人时不再每帧重算 A\*；
单位查地形走 `Terrain.current` 静态引用。

## 已知简化（原型故意砍掉的）

- 地形只有树林 / 密林 / 矿堆三种挡路格，没有河和悬崖（`Terrain` 支持，重新 paint 就能用回来）
- 无物流网络：没有传送带/路线规划，全靠农民两条腿
- 无音效、无存档
- 单位挤在一坨时会互相推挤减速（闲着的会让路，干活中的不让）
