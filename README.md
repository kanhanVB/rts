### 交货策略：为什么默认送仓库

加工厂**不会自动抢货**。默认所有原料原样入库，理由很直接：全自动加工会把木材全烧成木板，
而造农民要 30 木——原料一空就再也补不出人手了。

所以加工是**玩家点名**：选中农民右键熔炉/木工台，这批人才改送加工线（帝国式，全右键完成，没有额外按钮）。
产出口径 1:1（10 矿 → 10 铁锭），送错也不亏——熔炉只吃矿石，木材进去照样按原料入库。
想改回存原料，右键基地或仓库就行。

## 玩法循环

1. 开局 3 个工人自动上岗（2 采矿 1 伐木）
2. 攒资源 → 造仓库（就近收货）/ 熔炉、木工台（把原料变成铁锭、木板）→ 造兵营 → 出兵
3. 50 秒后 Goo 开始刷波（45 秒一波，越来越猛），朝你基地推进
4. **赢**：拆掉右上角巢穴，或清完第 10 波；**输**：基地被拆

Goo 的脾气：贴脸（70px 内）才咬单位，被打了必还手，平时直奔你建筑。
所以**工人是软肋**——交货路线穿过战场就会被啃，兵力要护着物流。

## 代码结构（每个文件一件事，对应巡游手册里的概念）

| 文件 | 职责 |
|---|---|
| `unit.gd` | 单位基类：移动、A\* 寻路跟随、软性分离、靠右让路、血条、绘制 |
| `terrain.gd` | 地形：网格 + 8 向 A\* + 拉绳平滑。移速/射程修正也长在这上面 |
| `worker.gd` | 农民状态机：采集 → 扛货 → 送货（交货点由玩家指派或就近自动） |
| `soldier.gd` | 剑士 / 弓手：自动索敌 + 追击玩家指定目标 |
| `engineer.gd` | 英雄工程师：建造（工地进度）+ 自卫 |
| `enemy.gd` | Goo：直奔建筑，贴脸咬人，挨打还手 |
| `building.gd` | 基地 / 兵营 / 仓库 / 熔炉 / 木工台 / 巢穴：挨打、掉血、被拆 |
| `site.gd` | 工地：工程师在旁施工，进度满转正 |
| `res_node.gd` | 矿 / 树：被采空就消失 |
| `economy.gd` | 资源账本：唯一出入账口径 + 建筑/单位成本表 + 入账流水 |
| `build_mgr.gd` | 建造管理：放置校验、扣钱、落工地、完工归档 |
| `wave_mgr.gd` | 波次管理：刷怪节奏、胜利判定 |
| `main.gd` | 地图、选择框、右键指令、UI、产能面板、自测套件 |

## 已知简化（原型故意砍掉的）

- 全平原：森林/河/悬崖的地形块撤掉了（`Terrain` 还在，重新 paint 就能用回来）
- 无物流网络：没有传送带/路线规划，全靠农民两条腿
- 无音效、无存档
- 单位挤在一坨时会互相推挤减速
