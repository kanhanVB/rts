```

```

**不用贴图**（逻辑完全一样，只换表现层）：在命令行末尾加 `-- --noart`

**换美术素材**：把新画的 PNG 按 `art_spec/ART_SPEC.md` 的文件名放进一个目录，然后


**跑自动化测试**（约 30 秒）：

```
E:\Godot\Godot_v4.7.2-stable_win64_console.exe --headless --path rts-demo -- --test
```

### 交货策略：为什么默认送仓库

加工厂**不会自动抢货**。默认所有原料原样入库，理由很直接：全自动加工会把木材全烧成木板，
而造农民要 30 木——原料一空就再也补不出人手了。

所以加工是**玩家点名**：选中农民右键熔炉/木工台，这批人才改送加工线（帝国式，全右键完成，没有额外按钮）。
产出口径 1:1（10 矿 → 10 铁锭），送错也不亏——熔炉只吃矿石，木材进去照样按原料入库。
想改回存原料，右键基地或仓库就行。

## 玩法循环

1. 开局 3 个工人自动上岗（2 采矿 1 伐木）；之后新造的农民也会自动去干活人少的那种资源
2. 攒资源 → 造仓库（就近收货）/ 熔炉、木工台（把原料变成铁锭、木板）→ 造兵营 → 出兵
3. 60 秒后 Goo 开始刷波（45 秒一波，每波 2 → 19 只，血量每波 +6%），**沿着地图上的土路**朝基地推进
4. **赢**：拆掉右上角巢穴，或清完第 10 波；**输**：基地被拆

Goo 的脾气：沿土路行军，路边 150px 内的建筑/工地会被拐过去啃；贴脸（70px 内）才咬单位，被打了必还手；走到路尽头就砸基地。
所以**房子盖在离路远的地方更安全，工人是软肋**——路边矿区的农民会被啃，兵力要守在路上护着物流。
城堡自带箭塔（射程 170，8 伤害 / 1.2 秒），能帮你顶住开局零星几只，挡不住大波。
地图上画着树林的地方不能盖房，右键点进去会自动落到林子边上。

## 代码结构（每个文件一件事，对应巡游手册里的概念）

| 文件 | 职责 |
|---|---|
| `unit.gd` | 单位基类：移动、A\* 寻路跟随、软性分离、靠右让路、血条、绘制 |
| `terrain.gd` | 地形：网格 + 8 向 A\* + 拉绳平滑。移速/射程修正也长在这上面 |
| `worker.gd` | 农民状态机：采集 → 扛货 → 送货（交货点由玩家指派或就近自动） |
| `soldier.gd` | 剑士 / 弓手：自动索敌 + 追击玩家指定目标 |
| `engineer.gd` | 英雄工程师：建造（工地进度）+ 自卫 |
| `enemy.gd` | Goo：沿土路行军，啃路边建筑，贴脸咬人，挨打还手 |
| `building.gd` | 基地 / 兵营 / 仓库 / 熔炉 / 木工台 / 巢穴：挨打、掉血、被拆 |
| `site.gd` | 工地：工程师在旁施工，进度满转正 |
| `res_node.gd` | 矿 / 树：被采空就消失 |
| `economy.gd` | 资源账本：唯一出入账口径 + 建筑/单位成本表 + 入账流水 |
| `build_mgr.gd` | 建造管理：放置校验、扣钱、落工地、完工归档 |
| `wave_mgr.gd` | 波次管理：刷怪节奏、胜利判定 |
| `main.gd` | 地图、选择框、右键指令、产能面板、自测入口 |
| `art.gd` | 美术入口：按 key 取贴图 / 锚点，按锚点画到指定高度，描边字、血条、脚下椭圆 |
| `art_data.gd` | 自动生成：每张贴图的尺寸和锚点（别手改，重跑 `tools/prepare_art.py`） |
| `fx.gd` | 一次性特效：尸体、黏液溅射、尘土、"+N 矿"飘字 |
| `hud.gd` | 王国保卫战风格 HUD：九宫格贴图主题、资源栏、波次横幅、指令卡、头像、小地图、结算 |
| `tools/prepare_art.py` | 素材预处理：抠纯色底、裁边、缩放、锚点；从地图图里分析出树林遮罩和土路中心线；生成 `art_data.gd` |

> 换皮的做法：逻辑、数值、寻路、测试一行没动，只改各节点的 `_draw()`——有贴图就画贴图
> （带走路颠簸、攻击前冲、受击闪红、黏液挤压回弹等小动画），没有就退回原来的程序化画法。
> 画面按 y 坐标排序（`y_sort_enabled`），下面的东西挡住上面的，像王国保卫战一样有前后层次。

## 性能

跑基准（120 单位挤在一起混战，直接计时单位逻辑）：

```
Godot --headless --path rts-demo -s bench.gd
```

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 单位逻辑 / 帧（123 单位） | ~17.5 ms（已超 60 帧预算） | ~2.8 ms |
| A\* 寻路 / 次（绕墙长路径） | ~14 ms | ~1.5 ms |

做法：寻路换成原生 `AStarGrid2D`；组成员每帧只取一次（`Unit._group()`）；
分离力用空间哈希只看周围 3×3 桶；Goo / 士兵索敌节流 + 目标粘性；Goo 追人时不再每帧重算 A\*；
单位查地形走 `Terrain.current` 静态引用。

## 已知简化（原型故意砍掉的）

- 全平原：森林/河/悬崖的地形块撤掉了（`Terrain` 还在，重新 paint 就能用回来）
- 无物流网络：没有传送带/路线规划，全靠农民两条腿
- 无音效、无存档
- 单位挤在一坨时会互相推挤减速
