## 怎么跑

**编辑器方式**：Godot 项目管理器 → Import → 选 `E:\workbuddyspace\2026-10-14-09-48-45\rts-demo\project.godot` → 打开 → **F5**

**命令行方式**（直接开玩）：

```
E:\Godot\Godot_v4.7.2-stable_win64.exe --path E:\workbuddyspace\2026-10-14-09-48-45\rts-demo
```

**不用贴图**（逻辑完全一样，只换表现层）：在命令行末尾加 `-- --noart`；**关掉战争迷雾**：加 `-- --nofog`

**换美术素材**：把新画的 PNG 按 `art_spec/ART_SPEC.md` 的文件名放进一个目录，然后

```
python3 tools/prepare_art.py <原图目录> rts-demo
```

脚本会裁透明边、统一缩放、算锚点（单位 = 脚底，建筑 = 底边中心），输出到 `art/`，并重新生成 `art_data.gd`。缺哪张图，游戏里对应物体就自动用程序化画法顶上。人物重绘的提示词见 `art_spec/CHARACTER_PROMPTS.md`。

**跑自动化测试**（用经典固定图，约 9 分钟）：

```
E:\Godot\Godot_v4.7.2-stable_win64_console.exe --headless --path rts-demo -- --test
```

只想跑新加的那几组（暂停/倍速、结算统计、轻 RTS、农民自保，约 15 秒）：末尾加 `-- --test --only=new`；
只跑 A 移动那条最脆的（几秒出结果，每秒打印位置/目标/路径）：`-- --test --only=solo`。

**看轻 RTS 演示**（不用动手，游戏自己演）：在命令行末尾加 `-- --showcase --nofog --seed=20261024`。
游戏会在路口盖兵营、出 8 个兵自己站好、一段一段放怪来撞防线，中途把集结点往前挪演示整队搬家，
最后演示"派一个兵出去再叫回来"。`show.py` 就是拿它录屏的（开机 → 等窗口出现 4.5 秒 → 录 → 杀进程，
全程不碰鼠标，碰了贴边会滚镜头）。

### 加工线：熔炉 / 木工台要人、要时间

加工不再是"送到就变"，而是一条看得见的流水线：

```
采集农民 ──送料──▶ 料场 ──工人守线读条──▶ 成品堆 ──工人扛回──▶ 仓库/基地（这时才入账）
仓库 ──（自取：工人顺路扛原料，仓库留底 30）──▶ 料场
```

- **没工人 = 停工**：建好的熔炉头顶冒"! 没人干活"。选中它按 Q 招工，或选闲农民右键它（点到门口守线的工人身上也算，每条线最多 2 人）
- **一炉要时间**：熔炉 5 矿 → 5 铁锭 / 5 秒，木工台 5 木 → 5 木板 / 4 秒；两个人都守在线上时读条快一倍
- **一个人干一阵停一阵**：他得自己把成品扛回仓库、再扛料回来，路上炉子就停了；**两个人轮班**（线上始终留一个）才连续出货
- **料从哪来**：采矿/伐木的农民右键加工厂 = 直接送进料场（送货工，脚下蓝点）；或者打开"自取"让工人回仓库时顺路扛原料——仓库至少留 30，不会把造农民的木头吃光；自取只把料场补到 20（再多就是把仓库的料压在门口），送货工能填满 40。关掉自取就只吃送来的料
- **物流决定产量**：工人每趟扛 10，跑得越远出货越慢——仓库盖在加工厂旁边，或者派人直接送料，产线才转得快
- **看现场**：门口左边料堆、右边成品堆（选中时标数字），干活时炉火亮、烟囱冒烟 / 锯末乱飞，停工时炉口变暗；工人脚下橙点
- **卡在哪**：缺工人 / 缺料 / 成品堆满三种状态都会冒头顶泡泡，产能面板（C）也会说人话
- 加工厂仍然**不会自动抢货**：不点名，采集的原料照样原样入库（不然木材全变木板，造农民的 30 木永远攒不出来）；送错也不亏，熔炉不吃木材，木材照原料入库

## 轻 RTS：兵随便动，但打起来一个一个拦（Kingdom Rush 那一路）

操作还是帝国式——**框选、右键、A/S/D/F 全都能用，兵听你的**。变的只是"接敌规则"：

```
   怪从这条路过来 →  ┌─ 防区（兵营集结点为中心，半径 115）──┐
                     │   兵1 ──钉住── 怪A   ← 一个兵只咬一只   │
                     │   兵2 ──钉住── 怪B   ← 一只怪只被一个钉 │
                     │   弓手 ──在后面射──（不占位、不挡路）   │
                     │   兵3 站好待命（不自动补位）             │
                     └──────────────────────────────────────┘
                              ▲
                        兵死了 = 少一个人，得回去再点
```

**两条规则，别的都是 RTS：**

- **1v1 独占**：近战兵咬上一只怪就"钉住"它（怪停下跟他对砍，走不掉）。这只怪别人不抢——旁边没活干的兵自动去找下一只，不会一窝蜂围着一只揍。弓手不占位，可以叠着射
- **默认守位**：兵出厂领一个"兵营集结点 + 自己的固定偏移"当站位点，自己走过去站好；怪进防区半径 115 就迎上去。**改了集结点，在场的老兵也跟着搬**——整队调防不用重新选兵下命令。弓手自动站到后排（朝基地那侧再退 58），剑士挡在前面挨咬

**剩下全是纯 RTS，随便玩：**

- **右键想点哪点哪**：空地 = 走过去，敌人 = 点谁打谁，Shift + 右键 = 排路点。给了令兵就听（信息栏会写「听你的手令」），暂时不守防区
- **A 攻击移动 / D 驻守 / F 巡逻** 照旧。兵在自由状态下**也一样一个一个拦**（1v1 规则对任何兵都生效），只是不再自动回防区
- **S 停止 / Q 回位** = 把手令交还出去，走回兵营的集结点接着守
- **追出去就松口**：钉住的目标跑出 200 距离，兵自己放口回站位点（守位状态下）；**优先还手**：刚咬过我的那只排最前
- **不自动补员**：死了就是死了，不会自己从兵营跑一个来补位。要补就选中兵营再点两个——人手永远是紧的
- **打不动怎么办**：**多盖一座兵营**（多一道防区）、**往前盖前哨**、或者**研究升级**（锻铁剑 / 锁子甲 / 战地包扎，见「升级」）

> 为什么这么改：纯 RTS 混战里最常见的画面是一堆兵追着同一只怪跑、队形散成一团，注意力全花在部队微操上。KR 那套的 1v1 让接敌变得**可读**——谁的兵在打谁一眼就看得清，剩下的精力留给采集、物流和"防线摆在哪"。
> 但没必要把兵的手脚捆起来：想拉一队兵去打野、去拆据点、去救火，右键就行，回到防区按一下 S。

一项只研究一次，研究完**全军立刻生效**（场上已有的兵、箭塔、农民、加工线都算），按钮随之消失，信息栏列出「已研究」。
花费多用铁锭 / 木板——升级和加工线绑在一起，产线转起来才升得动。按钮和队列图标右上角的金色小箭头 = 研究。

## 玩法循环

1. 开局 3 个工人自动上岗（2 采矿 1 伐木）；之后新造的农民也会自动去干活人少的那种资源
2. 攒资源 → 造仓库（就近收货）/ 熔炉、木工台 → **派农民进厂当工人**（每条线 2 人，原料要么右键派人送，要么工人自取）→ 造兵营 → 出兵（剑士吃铁锭、弓手吃木板）→ 基地 / 兵营**研究升级**（也吃铁锭木板）
3. 60 秒后开始来波次（45 秒一波，共 10 波，每波 2 → 24 只、三种怪混编，血量每波 +6%），**一只只沿着地图上的土路**朝基地推进；在路边盖**箭塔**拦截
4. **赢**：拆掉所有巢穴，或清完第 10 波；**输**：基地被拆

Goo 的脾气：沿土路行军，路边 150px 内的建筑/工地会被拐过去啃；贴脸（70px 内）才咬单位，被打了必还手；走到路尽头就砸基地。
所以**房子盖在离路远的地方更安全，工人是软肋**——路边矿区的农民会被啃，得把兵营盖过去、把集结点（防区）压在路边的矿区上护着物流（见「轻 RTS」）。
城堡自带箭塔（射程 170，8 伤害 / 1.2 秒），能帮你顶住开局零星几只，挡不住大波。
树林、矿堆旁边不能盖房，右键点进林子会自动落到林子边上；**所有房子都不能压在土路上**（会把整队怪卡死）。

## 塔防：箭塔 + 三种怪

**箭塔**（工程师 T，40 矿 50 木，施工 7 秒）：盖在**土路边**（压路会被拒），塔上弓手自动射路过的怪，**先打跑在最前面的**（离基地最近的）。
普通 Goo 和窜窜够不着塔上的弓手，从塔下走过只能挨射；只有岩壳会来拆塔——塔要配剑士守着。
选中箭塔按 **Q 升二级**（20 木板 + 15 铁锭，吃加工线的成品，塔防和经济绑在一起）。选中显示射程圈和击杀数。

|---|---|---|---|---|---|
| 一级 | 260 | 1 | 9 | 1.0 秒 | 190 |
| 二级 | 400 | 2（各射各的） | 14 | 1.0 秒 | 225 |

## 警钟和报警（守家）

**警钟**（帝国时代的 Town Bell）：按 **B**、点顶栏「警钟」或基地命令卡 **B 警钟**。外面的农民立刻放下手上的活，就近跑进**还有空位的**基地 / 仓库 / 前哨 / 箭塔躲着
（离得近的先挑位子，满了自动换下一处；哪儿都满了就在最近那座门口等空位）。

| 能躲的房子 | 能躲几个 | 躲在里面的人 |
|---|---|---|
| 基地 | 10 | 每人每轮多射一支箭（跟着房子上的弓手一起放，同样先打跑在最前面的） |
| 前哨 | 5 | 同上 |
| 箭塔 | 3（二级 4） | 同上 |
| 仓库 | 8 | 只躲着，不射箭 |

- 躲着的农民：怪打不着、选不中（编队里还记着，出来就选得上），人口照算；扛着的货进了收货的房子顺手交掉、宝箱遗物到手（箭塔不收货，攥着带进去）
- 房顶挂小牌子「农民头像 n/上限」，基地顶上挂一口钟一直晃；点房子信息栏写着躲了几个；还在路上跑的农民头顶一个红「!」
- 警钟响着时选农民**右键**基地 / 仓库 / 前哨 / 箭塔 = 指定躲进那座；另外下令（右键矿、移动、停止……）= 不躲了，听你的
- 躲着的房子塌了：里面的人跑出来，警钟还响着就去别处躲；警钟响着时新造的农民：出门的第一份差事记下，先进屋躲着
- **再按一次 B**（顶栏变成红字「解除警报」，基地命令卡 B 解除）= 警报解除：屋里的出来、路上的掉头，**各回各的活**——
  守线的回加工线、采矿的回原来那处（采空了找同类最近的）、扛宝箱的接着去扛、手上还有货的先交、走路的接着往原来的地方走

**挨打报警**：基地、前哨、农民被怪打，小地图上那儿一圈圈闪红圈（最后一下挨打起闪 4 秒），底下一行字「基地遭到攻击！/ 前哨遭到攻击！/ 农民遭到攻击！」，同时吹两声号角。
同一片地方（360px 内）接着挨打只续红圈、不再吹号；两声号角至少隔 3 秒；12 秒没再挨打这处才算消停，之后再挨打重新报警。兵挨打不报（打仗本来就看得见）。**M** 开关音效。

数值在 `building.gd` 的 `SHELTER_CAP` / `SHELTER_CAP_TOWER2`、`main.gd` 的 `ALERT_*`。音效在 `art/sfx/`（`bell.wav` 警钟、`clear.wav` 解除、`alert.wav` 报警号角），
由 `tools/make_sfx.py` 合成（`python3 tools/make_sfx.py` 重新生成）；想换成真录音，同名 wav 覆盖后重新导入一次就行。

### 农民自保（不用你一个个点名）

农民身边 95px 内冒出一只怪（或者刚被咬了一口），他自己放下手上的活，跑到**最近的一座己方基地 / 仓库 / 前哨 / 箭塔墙边**贴着，头顶顶一个红「!」；
怪离开 260px 以上、或者躲了 9 秒，就自己收工回去接着干原来的活（回加工线 / 接着采原来那处 / 先把手上这趟货交了）。

- 只管**挨着怪的那几个**，不是全城警钟：一只窜窜跑到东边，西边一堆农民不会全停工
- 跑的腿快 35%
- 想让他们**绝对安全**（怪打不着、还能帮忙射箭）：按 **B** 敲警钟进屋
- 玩家亲自下令（右键 / 停止 / 招工）= 立刻覆盖逃跑，听你的

数值在 `worker.gd` 的 `FLEE_R` / `FLEE_SAFE_R` / `FLEE_MAX_T` / `FLEE_SPEED`，扫描在 `main.gd` 的 `_check_worker_safety()`（0.5 秒一轮）。

## 节奏控制：暂停 / 倍速 / 结算

- **P 暂停**：时间停住（引擎 `time_scale` 归零），顶栏那格变红字「暂停」，屏幕上方一行大字提醒。暂停时照样能看地图、点选、改指令，再按 P 继续
- **+ / -**（或点顶栏「1×」）：1× / 2× / 3× 循环快进。镜头移动和提示条按**真实时间**走，3 倍速下镜头不会飞、提示不会一秒就没
- 赢了 / 输了：结算页列出**用时、击杀、阵亡、训练、峰值库存、科技、遗物**，点「再来一局」或按 **R** 重开（重开前会把 `time_scale` 复位，新局不会一开门就是 3 倍速）

统计口径在 `main.gd` 的 `stats` / `note_death()` / `on_trained()`；所有单位的死亡都经 `unit.gd` 的 `_report_death()` 上报，不用到处挂信号。


## Goo 据点 + 富矿（清野抢分矿）

主城跟前的矿迟早采完，**最肥的矿在 Goo 据点背后**：带兵把窝清掉，再在旁边盖仓库，就是 RTS 的扩张。

- **据点**：Goo 的小窝（比巢穴小一圈、偏橙色），不出波次、不算胜负（赢还是看巢穴/十波）；小地图上是橙点。点它能看守军几只、多久补一只、拆了缴获多少
- **两档**：近处（离主城 1000px 以内）3 只 Goo；远处再加 1 只岩壳，窝更厚、缴获也多（每张图至少一个远处档，都在近处就把最远那个升档）

| 据点 | 窝的血 | 守军 | 拆窝缴获 |
|---|---|---|---|
| 近处 | 420 | Goo ×3 | 80 矿 60 木 |
| 远处 | 560 | Goo ×3 + 岩壳 ×1 | 150 矿 100 木 |

- **守军脾气**（野怪式）：站在窝边的岗位上，不走土路；你的人进了**警戒圈（离窝 190px）**才扑上来，**打一只 = 全窝一起上**，打窝也一样
- **拴绳**：追出岗位 400px 就掉头回窝，回窝路上挨打也不理；没架打时每秒回 6% 血——打不过就撤，别磨
- **补兵**：窝还在，守军死一只就每 40 秒从窝里补一只同种的——先拆窝再清残兵最省事
- **富矿**每堆 600（普通矿 250），守军还活着（窝拆了但残兵还在也算）农民**不会自动去采**；你硬派也行（右键会提醒有守军），站在矿边上的照采
- 窝没拆之前，离窝 320px 内**不许盖房**（箭塔贴脸白嫖守军）；第一次有人走近（430px）横幅会提示"发现 Goo 据点"，清干净了也会提示

### 废墟和前哨（守住抢下来的地盘）

- 窝拆了留下一堆**废墟**（塌掉的碎石，中立：不挨打、不算胜负），点它能看倒计时、为什么停表
- **没人看着就倒计时 150 秒**，到点 Goo 回来**重新占窝**：窝立起来、守军刷满、背后的富矿又被看住；再拆只缴获一半（每回占一次再减半）。还剩 30 秒时横幅提醒
- **停表**：窝边的残兵还没清完 / 有剑士、弓手站在废墟 300px 内 / 旁边有前哨工地
- **前哨**（工程师 F，80 木 60 矿，施工 10 秒）：只能盖在废墟 300px 内。盖好废墟就清掉，**这片地永远是你的**：农民就近交货、能造农民（Q）、塔上一名弓手（射程 190，8 / 1.3 秒），视野 320

- 野地里散着 4 个**宝箱**、1 件**遗物**，Goo 据点窝边再藏 1–2 箱和 1 件遗物（有守军看着，先清场）

### 河、桥、浅滩、水车

- 每张随机图一条**河**横穿土路，把地图切开：土路过河处架**桥**（人和怪照常走），另有 1–2 处**浅滩**能趟过去（移速 ×0.45），别处过不去，得绕
- 房子不能压河、不能堵浅滩和桥头
- **水车**（工程师 D，50 木 20 木板，血 200）：贴着河岸盖，磨坊落在岸上、轮子泡在深水里（放置时自动朝向水那边，放不下会说为什么）。离它 260px 内的熔炉 / 木工台**最多 2 座一批快 30%**（读条 ×0.7，和熟练工匠、古老齿轮叠乘）；每条线找最近、还没带满的水车，放置预览和选中水车都能看到带动范围和连着哪几条线
- 东西走向的河段轮子够不着水（轮子长在磨坊侧面），斜着、竖着流的河段才能盖；每张图河边预留了 1–4 块不长树、正好能盖的空岸

### 分叉路

- 土路会**分叉**：主路走到大半处分出一支、绕个大弯再并回来（至少一条路分叉，另一条 35% 也分）；怪出巢**随机挑一条**走——箭塔盖在分叉前或并回来之后的路段，两边的怪都得经过

| 木工台 | 5 木 → 5 木板 | 4 秒（同上） | 最多 2 | 40 / 30 | 10 | 仓库 30，补到 20 |

数值在 `building.gd` 的 `RECIPES` / `OP_MAX` / `IN_CAP` 等常量。

## 性能

跑基准（120 单位挤在一起混战，直接计时单位逻辑）：

```
Godot --headless --path rts-demo -s bench.gd
```

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 单位逻辑 / 帧（123 单位） | ~17.5 ms（已超 60 帧预算） | ~2.8 ms |
| A\* 寻路 / 次（绕墙长路径） | ~14 ms | ~1.5 ms |

做法：寻路换成原生 `AStarGrid2D`；组成员每帧只取一次（`Unit._group()`）；
分离力用空间哈希只看周围 3×3 桶；Goo / 士兵索敌节流 + 目标粘性；Goo 追人时不再每帧重算 A\*；
单位查地形走 `Terrain.current` 静态引用。

## 已知简化（原型故意砍掉的）

- 地形：树林 / 密林 / 矿堆 + 一条河（深水挡路、浅滩减速），没有悬崖；经典固定图没有河
- 无物流网络：没有传送带/路线规划，全靠农民两条腿
- **兵不会自动补员**：死了就是死了，得回兵营再点两个（故意的，人手永远紧）；弓手不会边打边后退（被怪贴脸只能硬站），保弓手靠剑士挡前面
- 单位挤在一坨时会互相推挤减速（闲着的会让路，干活中的不让）

## 下一步可以加的（按性价比排序）

1. **物流网络**——路线/传送带，基建方向最重的一步（也是"RTS+基建"的立身之本）
2. **平衡调整**——数值全在代码顶部（波次表 `WAVES`、怪 `TYPES`、箭塔 `TOWER_LV`、兵 `PIN_RANGE` / `POST_LEASH`），先玩几局
3. 更多加工层级（铁锭 + 木板 → 零件？）与配套建筑；二级科技吃零件、要先研究一级
4. **兵营多集结点 / 走位线**：一座兵营能排 2–3 个站位点，出兵轮流分配，防线更厚
5. **镜头滚动 + 大地图**
6. 更多兵种 / 怪（远程 Goo、Boss）、更多塔（法师塔、炮塔）和塔的分支升级
